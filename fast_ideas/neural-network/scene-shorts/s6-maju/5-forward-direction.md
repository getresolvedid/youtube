# 5-forward — tutup, dan tempat namanya jatuh

Anggaran: `npm run gen`. Target peta `0:23–0:28`.

**Frame pertamanya = frame terakhir `4-keluaran`.**

## Di layar

1. satu **panah panjang** membentang dari atas jaringan sampai ke kartu
   tebakan, melewati seluruh lapis.

2. namanya muncul: **FORWARD PROPAGATION**

## Kamera

Diam.

## Gerak

- panah: digambar dari atas ke bawah 0,5 dtk — arah gambarnya sama dengan arah
  perjalanannya
- nama: `masuk()` sesudah panahnya sampai

## Kotak aman

Jaringan, angka, dan kartu di dalam `x` 90–920 dan `y` 240–1480.

## Dari unggahan

> **VO:** "That trip from input to output is called forward propagation."
> **Animation:** clean arrow spans the network. **Text:** FORWARD PROPAGATION

## Catatan

- **Namanya jatuh setelah perjalanannya ditempuh**, bukan di awal sebagai judul.
