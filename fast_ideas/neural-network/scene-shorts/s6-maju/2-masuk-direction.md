# 2-masuk — ketegangan

Anggaran: `npm run gen`. Target peta `0:03–0:08`.

**Frame pertamanya = frame terakhir `1-apa-terjadi`.**

## Di layar

1. ketiga angka **turun ke baris simpul teratas** dan berhenti di atasnya.

2. baris teratas menyala; dua baris di bawahnya masih gelap. teks layar:
   **MASUK**

## Kamera

Diam.

## Gerak

- angka turun: `E.power1out` 0,45 dtk, ketiganya bersamaan
- nyala lapis pertama: menyusul 0,1 dtk sesudah angkanya tiba — akibat, bukan
  kebetulan

## Kotak aman

Jaringan, angka, dan kartu di dalam `x` 90–920 dan `y` 240–1480.

## Dari unggahan

> **VO:** "The input enters the first layer." **Text:** INPUT

## Catatan

- **Dua lapis lain tetap gelap.** Kalau seluruh jaringan menyala di sini, scene
  3 tidak punya apa pun untuk ditunjukkan.
